# Lumi

Lumi 是一个无需安装、单文件运行的通用聊天客户端，面向**内网自建 / 代理转发**的 OpenAI 兼容接口，不绑定任何模型厂商。
用 Windows 自带的 .NET Framework 编译，不依赖 Electron、WebView2 或任何联网组件。

## 功能

- 品牌图标：左上角 Lumi 字样左侧显示浅黄色四角星光图标，程序 exe 使用同一图标
- 聊天窗口：流式输出（打字机效果）、停止生成、Markdown 渲染（标题 / 加粗 / 列表 / 行内代码 / 代码块 / 表格 / 引用）
- 消息操作：右键消息可复制、重新生成、编辑用户消息后重发、从该消息分支新会话；聊天区右下角有“回到底部”按钮
- 代码块工具栏：语言标签、简单语法高亮、复制按钮；代码块有独立整块背景和边框
- 阅读布局：助手回复不使用气泡，按连续 Markdown 文档平铺；正文区域最大宽度约 75%，行距约 1.5–1.6
- 流式渲染：已闭合的块做完整高亮，未闭合块轻量追加；UI 按 60ms 节流刷新
- 输入区：圆形向上箭头发送按钮位于输入框下方，当前模型显示在箭头左侧；支持文件拖拽和 `@` 引用工作区文件
- 可配置接口：接口地址、接口路径（可填完整 URL）、API Key、模型名
- 单模型配置：在设置里配置一种模型，主界面只在发送按钮左侧显示当前模型，不提供多模型切换
- 启动自检：打开程序时自动检查接口 / Key / 网络是否可用，就绪状态常显在聊天区左上角
- Token 显示：Token 估算单独显示、常显，不和就绪状态混在一起
- HTTP 代理：`host:port` + 可选账号密码；也可以**忽略系统/环境变量代理**（等价 `trust_env=False`），内网直连时用
- 工作区文件：选一个目录后，界面里可浏览、打开、插入、新建、重命名、删除文件，也能把最后一条回复导出成文件；支持 `.py` / `.c` 等文本和 `.xlsx` / `.docx`
- AI 工具调用：开启后模型可调用 `list_files` / `read_file` / `write_file` / `delete_file` 操作工作区文件，能读写代码文件，也能生成 / 读取 Excel、Word；工具调用显示为可展开卡片，写文件前显示行级 diff
- 省 Token：上下文预算、旧工具结果压缩、`read_file` 分页、重复读取去重、简洁回答（详见下文）
- 配置记忆：接口地址、Key、模型、代理、主题等保存在本机，重开 exe 不用重新填写
- 主题模式：设置里可选 **跟随系统 / 浅色 / 深色**，保存后立即同步全部颜色；跟随系统时会自动响应 Windows 主题变化
- 配色：浅色主画布 `#FFFFFF`、侧边栏/次级表面 `#F7F8FA`、用户输入框 `#FFF8E1`；深色主画布 `#151922`、侧边栏 `#121316`、用户输入框 `#1F1F23`；强调色浅黄
- 多会话：新建对话、历史会话切换；按日期分组、置顶、重命名和删除（三个点菜单，删除二次确认）
- 内网适配：可忽略 HTTPS 证书错误（自签名证书）
- API Key 使用 Windows DPAPI（当前用户）加密后保存

## 运行

直接双击 `Lumi.exe`。第一次打开后：

1. 点左下角 **设置**（或按 `Ctrl+,`）
2. 填写：
   - **接口地址**：如 `https://api.openai.com` 或 `http://10.0.0.5:8000`
   - **接口路径**：默认 `/v1/chat/completions`；如果网关给的是完整地址，也可以直接把完整 URL 填到这里
   - **模型名称**：如 `gpt-4o-mini`、`qwen2.5-72b-instruct`，以服务端为准；程序只使用这一种模型
   - **API Key**：内网网关的密钥（可留空，由网关自行鉴权时）
   - **HTTP 代理**：如 `127.0.0.1:7890`，不需要就留空
   - **忽略系统代理与环境变量代理**：默认已勾选，勾选时等价 `trust_env=False`，强制直连；内网地址（如 `http://10.x.x.x`）被系统代理接管导致连不上时保持勾选。需要走系统代理时取消勾选。
   - **主题**：右上角可选 **跟随系统 / 浅色 / 深色**；切换时界面、文字、边框、强调色会一起变化。
   - **上下文预算**：默认 `12000`（估算 token）。超预算会自动省略较早消息、压缩旧工具结果，越小越省；`0` = 不限制。
   - **简洁回答**：默认勾选，在系统提示词末尾追加“先给结论、省略寒暄”，减少输出 token；需要详细回答时取消。
   - 自签名证书的内网 HTTPS，勾选 **忽略 HTTPS 证书错误**
3. 点 **测试连接**（或按 `F5`），成功后再点 **保存**

接口按 OpenAI 兼容协议调用：`POST {接口地址}{接口路径}`，请求头 `Authorization: Bearer {API Key}`。

## 工作区与 AI 工具调用

主窗口输入框下方的 **工作区** 按钮（或 `Ctrl+O`）里：

1. 点 **选择…** 指定一个工作区目录
2. 勾选 **允许 AI 读写工作区文件（函数调用）**（默认可再勾选 **写入 / 删除前弹窗确认**）
3. 点 **保存**。之后对话时模型就能调用：

| 工具 | 作用 |
| --- | --- |
| `list_files` | 列出工作区（可指定子目录，最多 120 项；文件带 `[表格]` / `[文档]` / `[代码]` 标记） |
| `read_file` | 分页读取文本、`.xlsx`、`.docx`（默认 200 行、单次 ≤5600 字符；用 `start_line` / `max_lines` 继续读） |
| `write_file` | 写入文本，或生成 `.xlsx` / `.docx`（目录不存在会自动创建） |
| `delete_file` | 删除文件或空目录 |

所有路径都限制在工作区内，`..` 和绝对路径会被直接拒绝；模型最多连续调用 12 轮工具。达到上限后会自动关闭工具，再请求模型输出一段文字总结，不会直接空手结束。
写入 / 删除确认框提供 **允许 / 本轮全部允许 / 拒绝** 三个选项。同一文件在同一轮对话里只确认一次；内容完全相同的重复写入会自动跳过；连续 3 轮要求写入相同内容时会自动停止并生成总结。
开启工具时，系统提示词会要求“先实际调用工具、再汇报结果”；如果模型仍然只回复“已写入”却没有调用 `write_file`，客户端会自动补问一次。自动重试后仍未检测到实际写入时，会显示本地警告，而不是把假成功当成结果。
面板里还可以手工浏览子目录、打开文件、把文件内容插入输入框、新建/重命名/删除，以及把最后一条回复保存成文件。

> 注意：工具调用要求内网网关支持 OpenAI 的 `tools` / `tool_calls` 字段；模型不支持时不要勾选工作区里的工具开关。

## 界面交互

- **历史对话**：按“置顶 / 今天 / 昨天 / 更早”分组；每个会话右侧的 `⋯` 菜单可重命名、置顶、删除（删除需要再点一次确认）。
- **消息操作**：右键任意消息可复制；助手消息可重新生成；用户消息可编辑后重发；任意消息可“从此处分支”新会话。
- **工具卡片**：工具调用显示为可展开卡片，包含参数、结果、耗时；写文件会附带行级 `+ / -` diff，读文件显示读取行范围。
- **代码块**：独立整块背景（浅色 `#F5F6F8`、深色 `#1B1F27`），带边框、语言标签、简单语法高亮和复制按钮；空行、缩进和行尾空格都包含在块内。
- **表格 / 引用**：Markdown 表格按列绘制网格，引用使用左侧竖线；标题分级显示，列表支持有序 / 无序。
- **阅读宽度**：消息列约 75% 宽并居中，输入框与消息列对齐；长文不铺满整屏。
- **引用文件**：把文件拖进输入框，或输入 `@` 选择工作区文件，会把文件内容作为引用块插入输入框。

## 支持的文件类型

| 类型 | 读取 | 写入 |
| --- | --- | --- |
| 文本 `.txt` `.md` `.py` `.c` `.h` `.cpp` `.cs` 等 | 按 UTF-8 读取，失败时按 GBK 兜底 | UTF-8 写入 |
| Excel `.xlsx` | 读取所有工作表，按 TSV 输出；日期显示为 Excel 序列值 | 按 CSV / TSV / Markdown 表格生成单工作表；纯数字自动写成数值 |
| Word `.docx` | 读取段落、标题和表格；表格按 TSV 输出 | 按纯文本段落生成；`#` / `##` / `###` 映射为标题 |

- 旧版 `.doc` / `.xls` 以及宏 / 模板格式（`.docm` / `.xlsm` / `.dotx` 等）不解析；请先用 Word / Excel 另存为 `.docx` / `.xlsx`。
- `.xlsx` / `.docx` 写入会**重建**文件，不保留原文件的格式、公式、图片、批注；适合让 AI 生成新文件，不适合原地改格式。
- 中文文件名和中文内容都支持；`.xlsx` 多工作表可读，写入固定生成 `Sheet1`。
- 在工作区面板里新建文件或导出回复时，把文件名写成 `.xlsx` / `.docx` 就会走对应格式；`.py` / `.c` 直接按文本处理。

## 省 Token 的做法

每次请求发出前都会先经过 `ContextBudget` 压缩，界面和会话文件里保存的原文不受影响：

1. **上下文预算**：只把最近、且能放进预算的消息发给模型（默认约 12000 token）。最后一条用户消息和最近一轮工具调用一定会保留；右上角单独的 Token 栏会显示本次请求的估算上下文大小。
2. **旧工具结果压缩**：最新一轮工具结果最多保留 6000 字符；更早轮次压缩到约 400 字符，连续工具调用时不会把每一轮的大文件内容反复回传。
3. **工具参数压缩**：较早轮次的 `write_file` 大段 `content` 会替换成省略提示，仍然保持合法 JSON。
4. **`read_file` 分页**：默认只读 200 行 / 5600 字符；文件更长时返回行号和 `start_line` 提示，模型可以按需继续读，而不是一次塞 200 KB。
5. **重复读取去重**：同一轮里重复读取同一个未变化的文件，第二次只返回简短说明；文件大小/修改时间变化后会自动重新读取。
6. **`list_files` 上限**：最多列 120 项，避免超大目录一次占满上下文。
7. **思考内容按需回传**：只有请求携带 `tools` 时才回传 `reasoning_content`（API 在没有工具时会忽略它，回传只会白花输入 token）。
8. **简洁回答**：默认在系统提示词末尾加一句“先给结论、省略寒暄”，减少输出 token；不需要可在设置里取消。

> 预算为估算值（中文约 0.62 token/字、英文约 0.3 token/字符），实际计费以服务端 `usage` 为准。把预算设为 `0` 可完全关闭压缩（会明显增加 token 消耗）。

## 配置文件

保存在 `%APPDATA%\Lumi\`：

- `config.ini`：接口地址、模型、代理、工作区目录、上下文预算（`ContextTokens`）、简洁回答（`Concise`）与工具开关等；API Key / 代理密码以 DPAPI 加密（只能由当前 Windows 用户解密）
- `sessions.dat`：历史会话（正文 Base64 编码，避免换行与特殊字符问题）

可用环境变量 `LUMI_HOME` 指定其他数据目录（便携/测试用）；默认是 `%APPDATA%\Lumi\`。从旧版升级时，会自动从旧数据目录复制 `config.ini` / `sessions.dat`（如果新目录里还没有）。

删除该目录即可恢复出厂设置。

## 从源码编译

需要 Windows 自带的 .NET Framework 4.x（`csc.exe`），无需安装 SDK、无需联网：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `Lumi.exe`（约 139 KB）。修改图标后执行 `make-icon.ps1` 重新生成 `app.ico`。

`tools\` 下还有离线回归测试（`TokenBudgetTest.cs`、`ReadToolTest.cs`、`OfficeFileTest.cs`、`OfficeToolTest.cs`、`WriteClaimTest.cs`、`ToolTest.cs`、`LoopTest.cs`），用同样的 `csc.exe` 编译后即可运行，不需要联网。

## 已知限制

- 仅支持 OpenAI 兼容的 Chat Completions 协议；若内网网关使用其他协议，需要自行调整 `src/ChatClient.cs`
- AI 工具调用依赖网关支持 `tools` / `tool_calls`，且要求模型会使用函数调用
- 文本文件单次最多扫描前 200 KB；`.xlsx` / `.docx` 先解包成文本，单次最多提取约 20 万字符
- `.xlsx` 读取单表最多 2000 行 / 100 列，超出会截断；写入单表最多 20000 行 / 256 列
- 旧版 / 宏 / 模板格式（`.doc` / `.xls` / `.docm` / `.xlsm` 等）不支持，请另存为 `.docx` / `.xlsx`
- `.xlsx` / `.docx` 写入会重建文件，不保留原格式、公式、图片、批注
- `read_file` 默认只返回 200 行 / 5600 字符，超出时需模型用 `start_line` 继续读取
- 代理为 HTTP 代理（不支持 SOCKS）
- 窗口标题栏颜色跟随系统主题，不随应用内明暗主题变化
- 上下文按“上下文预算”裁剪（默认约 12000 token）；超出后会省略较早消息并压缩旧工具结果。需要完整历史时可调大预算，`0` 表示不压缩（可能很费 token）
